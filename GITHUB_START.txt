КАК ОТКРЫТЬ ОТДЕЛЬНО В VS CODE

1. Распакуйте архив в отдельное место, например C:\Projects.
2. Не помещайте папку внутрь старого репозитория с другими проектами.
3. В VS Code выберите Файл → Открыть папку.
4. Выберите django-blog-crud — папку, в которой лежит manage.py.
5. Запустите start_windows.bat, затем откройте:
   http://127.0.0.1:8000/articles/
